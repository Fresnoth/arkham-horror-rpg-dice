# Documentation Images

Store repository-owned README screenshots in this directory. Palette previews use quality-90, 512 x 512 WebP files so every die has the same canvas and README display size. Use descriptive lowercase names, for example:

- `investigator-aged-ivory.webp`
- `archetype-guardian.webp`
- `horror-eldritch-green.webp`

Reference images from the repository README with a relative path:

```markdown
![Horror Eldritch Green d6](docs/images/horror-eldritch-green.webp)
```

Do not commit screenshots containing server addresses, access keys, player email addresses, or other private world information.
